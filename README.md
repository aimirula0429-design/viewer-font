# viewer-font
一个单文件网页工具：导入你自己的字体，查看任意长度的文本。

在线访问：https://aimirula0429-design.github.io/viewer-font/

---

## 功能

- **字体导入**：支持 ttf / otf / woff / woff2，本地加载，不联网
- **文本导入**：支持导入文本文件或直接粘贴，字数不限，全文渲染不截断
- **排版调节**：字号、行高、字间距、字重、对齐方式
- **四种主题**：深色 / 浅色 / 护眼棕 / 白纸黑字
- **导出**：长图 PNG、PDF

---

## 使用方式

1. 用浏览器打开网页
2. 点「设置」展开面板，导入字体文件
3. 点「导入」或「粘贴」载入文本
4. 调节参数，点「导出」保存为图片或 PDF

也可以直接把文件拖进页面（自动识别是字体还是文本）。

## 技术说明

- 单文件，无外部依赖，无构建步骤
- 字体加载使用 `FontFace` API
- 导出使用 Canvas 自绘排版（手动逐字测量宽度，支持中文自动换行）
- PF 输出走浏览器打印通道
